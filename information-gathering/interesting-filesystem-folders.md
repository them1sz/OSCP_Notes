# Interesting Filesystem folders

#### MySQL - Xampp Folders&#x20;

```markdown
xampp\mysql\data\<database-name>
xampp\mysql\data\creds\creds.ibd (binary file with credentials) 
```

#### SSH Private Keys

```markdown
.ssh/id_rsa
.ssh/id_dsa 
.ssh/id_ecdsa (modern)
.ssh/id_ed25519 (modern, recommended)
.ssh/id_ecdsa_sk
.ssh/id_ed25519_sk
```
